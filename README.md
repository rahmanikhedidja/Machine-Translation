# Simple French → English Translator Using an Electronic Dictionary

## Description
This project implements a basic word-by-word translation system from French to English
using an electronic dictionary in Python. Each word in the input text is looked up in
the dictionary, and if a word is not found, it is shown in brackets.

## Example
- Input text: `"bonjour monde je suis heureux"`
- Output text: `"hello world I am happy"`

## Methodology
- Define a dictionary with French words as keys and English translations as values
- Split the input text into words
- Translate each word using the dictionary
- Join the translated words to form the output text

## Tools
- Python

## Academic Context
Developed as part of a Natural Language Processing (NLP) course to demonstrate
a simple lexical-based machine translation approach.
